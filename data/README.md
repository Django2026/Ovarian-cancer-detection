# Dataset: Predict Ovarian Cancer

- **Source**: [Kaggle - Predict Ovarian Cancer](https://www.kaggle.com/datasets/saurabhshahane/predict-ovarian-cancer)
- **Original Study**: Mi et al. (2020), *Data for: Using Machine Learning to Predict Ovarian Cancer*, Mendeley Data, V11, doi:10.17632/th7fztbrv9.11
- **License**: CC BY 3.0 Unported

## Structure
- `Supplementary data 1.xlsx`: Full raw cohort data.
- `Supplementary data 2.xlsx`: Biomarker dictionary and descriptions.
- `Supplementary data 3.xlsx`: Imputed training partition without CA72-4.
- `Supplementary data 4.xlsx`: Raw training partition.
- `Supplementary data 5.xlsx`: Raw testing partition.

## Target Variable
- Column: `TYPE`
  - `1`: BOT (Benign Ovarian Tumor)
  - `0`: OC (Ovarian Cancer)
